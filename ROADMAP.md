# Roadmap

> Phase-based with dependency tracking. Tasks within a phase are independent.
> Statuses: `TODO` | `IN PROGRESS` | `DONE`
> Priorities: `P0` (must have) | `P1` (should have) | `P2` (nice to have)
> Sizes: `[S]` (small) | `[M]` (medium) | `[L]` (large — consider splitting)
> Flags: `[SPIKE]` — needs investigation before implementation; `[BLOCKED: reason]` — waiting on external dependency
> Dependencies: `depends: #x, #y` — all must be complete before task starts
> Scope: `scope: path/` — relevant files/directories for the task (required)
> Acceptance: `AC:` — machine-verifiable criteria (indented below task)
> Milestones: `MILESTONE:` — marks demo-able project states
> Completed phases are collapsed to one-line summaries.

## Tech Stack
- Language: Python 3.13 (uv-managed)
- Framework: typer CLI · httpx · pydantic · SQLite · polars/numpy/scipy · Playwright for Python (installed Edge/Chrome channel) · anthropic SDK · FastMCP
- Key conventions: follow `CLAUDE.md` invariants. Workers propose and only `executor/` writes to ESPN. **No live ESPN writes during development** (`--dry-run` only). League settings are data. Projections are stat lines. Selectors live only in `src/fm/browser/selectors.py`. Design reference: `docs/DESIGN.md`.
- Shared-file rules:
  - #1 declares every v1 dependency, so later tasks never edit `pyproject.toml` or `uv.lock`.
  - CLI command groups are auto-discovered from `src/fm/commands/` (one file per group), so tasks never edit `cli.py`.
  - #3 defines the full v1 schema.
  - Decision modules register via `src/fm/decide/registry.py` (#7); executor flows register via `src/fm/browser/flows/__init__.py` (#19).
- Build: `uv sync --locked`
- Test: `uv run pytest -q`
- Lint: `uv run ruff check . && uv run pyright`
- Dev: `uv run fm --help`

## Phase 5 — DONE
Built: `fm.decide.lineup` (#20) solves a week's NFL lineup as an assignment problem (`scipy.optimize.linear_sum_assignment`) in priority order: every active slot filled with a player who will play (an OUT, bye or no-game starter is benched whenever any legal arrangement, including shifting starters between slots, replaces him; empty slots filled), then expected points (`p_active` × the league's own scoring of the period's stored lines, blended in memory with `data/blend_weights.toml`), then the fewest moves; with an opponent outlook it switches to win probability (normal approximation; a search over expected + w·variance seeded from the expected-points lineup, so the switch never lowers P(win)) when the expected-points lineup wins with P ≥ 0.75 or ≤ 0.25; locks are hard constraints (ESPN `lineupLocked` at the last sync, or `plugin.locks(period, schedule, lock_type=settings.lineup_lock_type)` passed; a bye never locks per game; `UNKNOWN` raises `LineupError`), IR players stay put and nobody moves to IR; `plan_lineup` reads the roster snapshot, the `players` rows, the projection lines and availability (a stored row no older than the player row, else `assess()`, for `p_active` only; whether he has a game comes from the schedule in hand, never the row, which may have been assessed without one; OUT, IR, suspended, off-roster or without a game is 0), and `propose_lineup` drafts up to two `LineupPayload` proposals against the synced roster (`bench_inactive`: the best lineup that keeps every playing starter; `lineup`: the full optimum when it goes further), each with a deadline (the earliest lock among the moved players), engine numbers, a template rationale and a dedupe key, through `fm.proposals.propose` (policy refusals reported, never raised), registered as `("nfl", "lineup")`. `fm.model.valuation` (#21): `PlayerOutlook` weekly expected points (this week's blend × `p_active`; later weeks ESPN's `102026` season line per game × that week's games × `health`, the projected `GP` over the games left), `start_value` as a max-weight slot assignment with later-week holes filled at replacement level, replacement level from the league's actual wire, ROS value with playoff weeks weighted up, `LeagueValuation` / `load_valuation(include_rostered=...)`, `slot_instances`, `eligible_active_slots`; settled that `102026` (split 0) is ESPN's rest-of-season line and `122026` is unread (docs/espn-api.md section 1 #10). `fm.decide.waivers` (#21): ranks (add, drop) pairs by value over replacement with a FAAB bid heuristic inside `faab_bid_cap`, `find_untouchables` protected, timed to the league's waiver run from `settings.roster_lock_type` (a free agent whose game this period has started is skipped with a reason; an `UNKNOWN` roster lock type skips every candidate with a warning), a per-matchup-week budget from `max_transactions_per_week − acquisitions_this_week` that agrees with `evaluate()`, emitting `WaiverPayload` / `AddDropPayload` as `("nfl", "waivers")`. `fm.model.availability` (#22): `p_active` from the effective designation (the NBA official injury report replaces ESPN's status for that day's game, matched by name, team and US Eastern day;
