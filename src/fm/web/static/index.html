Proposals

Approving records your decision; fm run (or the scheduled tick) executes it at its time. Trades always wait for you.

The engine's plan for the synced scoring period. Read-only: nothing is stored or sent.

The pickups the engine would make and the best free agents by rest-of-season value. Read-only.

Reports

Settings

Changes are written to config.toml (the previous file is kept as config.toml.bak) and apply from the next tick.

Health
